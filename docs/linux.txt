1.What is linux?
Answer- Linux is an open-source operating system (OS).
It is based on Unix principles.
Created by Linus Torvalds in 1991.
The Linux kernel is the core part that communicates between hardware and software.
It manages hardware resources, like CPU, memory, and storage.
Linux is free to use, modify, and distribute.
It is used in a variety of devices: servers, desktops, smartphones (Android), and embedded systems.
Linux comes in different versions called distributions (distros), e.g., Ubuntu, Fedora, Debian, CentOS.

2.Three Commands:
Answer- 
1. ls – List Files and Folders
Shows all files and directories in the current folder.
Examples:
ls → list files
ls -l → list with details (size, date, permissions)
ls -a → show hidden files

2. cd – Change Directory
Moves you between directories (folders).
Examples:
cd Documents → go into the Documents folder
cd .. → go up one level
cd ~ → go to home directory

3. pwd – Print Working Directory
Shows the full path of your current location.
Example:
pwd → /home/username/Documents
