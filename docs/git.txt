1.What is Git?
Answer- Git is a distributed version control system (VCS).
It tracks changes made to files and source code.
It stores the history of a project.
It allows developers to revert to previous versions when needed.
It helps multiple developers work on the same project efficiently.
Git was created by Linus Torvalds in 2005.

2.Why is git useful?
Answer-Tracks Changes: Keeps a record of all modifications.
Version History: Allows you to restore older versions of files.
Collaboration: Multiple developers can work on the same project simultaneously.
Branching: Developers can create separate branches to work on new features without affecting the main code.
Backup: Code history is safely stored and can be recovered if mistakes occur.
Code Management: Makes it easier to organize and maintain large projects.
Industry Standard: Widely used in software development.

3.Difference between git and github.
Answer-
Git                          	GitHub
A version control system	A platform for hosting Git repositories
Installed on a local computer	Cloud-based service
Tracks and manages code changes	Stores and shares Git projects online
Can work without internet	Usually requires internet access
Free and open-source software	A service owned by GitHub 
Used for version control        Used for collaboration, code sharing, and project management
